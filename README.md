Crescent Bay — a complete 2D top-down open-world crime game built for make.fun's "Make GTA 6" bounty. Play as Rook: explore a sun-soaked coastal city on foot and by car, steal any car, outrun the police, take jobs from fixers Mara and Dex, and climb from a first job to the Bay Finale. Vanilla Canvas 2D, procedural art, synth WebAudio sound, deterministic city — no libraries, no network, no external assets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
